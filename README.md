# 📚 Concurso Store

## Sistema de Venda de Materiais para Concursos Públicos

### Visão Geral

A Concurso Store é uma plataforma de e-commerce especializada em materiais de estudo para concursos públicos, com foco em um método exclusivo de memorização. Desenvolvida para ser escalável, segura e com uma experiência de usuário excepcional.

### Metodologia de Ensino

Nossa abordagem é baseada em quatro pilares fundamentais:

1. **Mapas Mentais** - Organização visual do conteúdo para facilitar a compreensão e conexão entre temas
2. **Flashcards Inteligentes** - Sistema de repetição espaçada para fixação de longo prazo
3. **Revisão Programada** - Algoritmo que define os melhores momentos para revisar cada conteúdo
4. **Simulados Estratégicos** - Treino com questões no formato da banca e acompanhamento de desempenho

### Stack Tecnológica

| Tecnologia | Finalidade |

### Funcionalidades

- ✅ Catálogo de materiais por concurso
- ✅ Checkout integrado com Stripe
- ✅ Múltiplos métodos de pagamento (cartão, boleto)
- ✅ Páginas de sucesso e cancelamento
- ✅ Health check para monitoramento
- ✅ Design responsivo e profissional
- ✅ Variáveis de ambiente para configuração segura
